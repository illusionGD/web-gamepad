# web-gamepad

## 2.0.0

### Major Changes

- Replace the global v1 API with an instance-based manager, uppercase logical keys, per-device custom mappings and extension keys. Add automatic device handover, explicit scene stacks, click/longpress/cancel events, stick press support, capability/raw-state inspection and complete lifecycle cleanup. See the v2 migration section in the README.

  Add same-device button combos via onCombo(), with typed click/longpress/cancel events and optional member-button suppression.
